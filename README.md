# ガラガラ BINGO NIGHT

忘年会で使える、ガラガラ抽選機つきのビンゴ抽選アプリです。

- 公開ページ: https://sny0.github.io/bingo-party/
- 1〜75から重複なく抽選。抽選機の高速回転、外周ランプ、集中線、玉の光跡、金色の番号カットイン、ファンファーレつき
- 最新の番号と1〜75の一覧を常時表示。画面の高さに合わせて番号一覧を配置します
- ガラガラの演出は抽選中だけダイアログで表示し、終わると一覧へ戻ります。「演出をスキップ」やEscでも戻れます
- スマホ・タブレット・PC対応。PCはスペースキーでも抽選できます
- 抽選結果をブラウザに自動保存し、再読み込み後も継続
- 履歴のJSON保存・読み込み、イベント名、音量、演出時間の変更
- 全画面表示（対応ブラウザ）。OSの「視差効果を減らす」設定にも対応
- 初回アクセス・読み込み完了後は、サービスワーカーのキャッシュでオフライン利用可能

## 当日の使い方

1. 会場で使うPCで公開ページを開きます。
2. 右上の設定からイベント名や演出時間を設定します。
3. 「ガラガラを回す」またはスペースキーで1球ずつ抽選します。
4. 必要に応じて「履歴を保存」でバックアップします。

**結果は端末・ブラウザごとに独立しています。** スマホと会場PCの抽選結果は自動同期されません。引き継ぐ場合は履歴ファイルを保存し、設定の「履歴ファイルを読み込む」から取り込んでください。プライベートブラウズやブラウザのデータ削除では、自動保存の履歴が消えることがあります。

初回アクセスにはネット接続が必要です。会場でオフライン利用する場合は、同じ端末・ブラウザであらかじめページを開いておいてください。ブラウザによるキャッシュ削除に備え、当日はネット接続と履歴バックアップも確保してください。

## 開発

Node.js 20.19以降。外部パッケージのインストールは不要です。

```sh
npm run dev
# http://127.0.0.1:4173

npm test
npm run build
```

`dist/` に公開ファイルを生成します。ES Modulesとサービスワーカーを使うため、HTMLのダブルクリックではなくHTTPサーバーか公開ページから開いてください。

## リポジトリと公開

ソースと公開ファイルはこの1つのリポジトリで管理します。外部依存のない静的アプリなので、`main` ブランチのルートをGitHub Pagesで直接公開します。独自のActionsワークフローや追加の認証権限は不要です。

更新するときは `npm test` と `npm run build` が成功することを確認してから、`main` にcommit・pushしてください。GitHub Pages標準の公開処理でサイトが更新されます。`dist/` は配布用ビルドの確認に使い、Gitには含めません。

- `index.html`: 画面と抽選機のSVG
- `styles.css`: PC・スマホのデザイン
- `app.js`: 操作、アニメーション、音、保存
- `src/bingo.js`: 抽選と履歴の検証
- `sw.js`: オフラインキャッシュ
- `tests/`: 抽選・保存・復元のテスト

抽選にはWeb Crypto APIの乱数と、偏りを避ける棄却法を使っています。未抽選の番号から毎回選び、演出を開始する前に結果を保存します。画像・音・フォントの外部配信への依存はありません。
